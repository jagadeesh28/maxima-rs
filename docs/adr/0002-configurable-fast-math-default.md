# Configurable Fast-Math Semantics with Real-Number Default

Context: The e-graph engine needs to decide which algebraic rewrites are valid (e.g., reassociating addition, cancelling `x / x → 1`). IEEE-754 floating-point breaks these identities due to rounding, subnormals, and NaN/Inf. We chose to default to real-number ("fast-math") semantics, treating all floats as elements of ℝ, because the primary use case—generating optimized numerical kernels for solvers and simulation—requires aggressive algebraic simplification. A per-function `#[fast_math = false]` flag disables unsafe rewrites for strict IEEE-754 correctness when needed. The alternative of defaulting to strict mode would render most algebraic optimizations (Horner form, distributive factoring, term cancellation) illegal, defeating the project's purpose.

# Hybrid E-Graph and Procedural CAS Architecture

**Status**: Accepted

Context: Expanding maxima-rs into a full-featured Computer Algebra System on-par with Wolfram Mathematica requires algorithms such as polynomial factorization, partial fractions, Risch/Hermite symbolic integration, Gruntz limits, and differential equation solvers. Running bidirectional equality saturation over operations like polynomial expansion, factorization, and integration by parts leads to state-space explosion in the e-graph. We decided to establish a strict architectural boundary between e-graph rewriting and procedural CAS algorithms: `sym-core/src/rules/` and `saturate.rs` handle equivalence-preserving algebraic and trigonometric simplification and FLOP-optimal extraction, while procedural CAS routines (`poly`, `integrate`, `limit`, `series`, `solve`) are implemented as dedicated deterministic modules operating directly on `Expr` ASTs, invoking `diff.rs` for derivatives and `pipeline.rs` for local canonical simplification. This guarantees Mathematica-grade computational speed, bounded memory usage, and predictable termination while preserving compile-time zero-overhead code generation.
